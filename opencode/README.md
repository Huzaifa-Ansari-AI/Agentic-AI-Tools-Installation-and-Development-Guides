# OpenCode

An open source AI coding agent for the terminal, desktop, and IDE.

## What is OpenCode?

OpenCode is an agentic AI tool that helps you write, review, and refactor code. It works with your codebase to understand structure, suggest improvements, and implement changes based on your requirements. Available as a terminal UI, desktop application, or IDE extension.

## Why Use OpenCode?

- **AI-Powered Development** — Get suggestions and implementations from advanced AI models
- **Full Codebase Understanding** — Analyzes your project structure and coding patterns
- **Multiple Interfaces** — Terminal (TUI), Desktop App, or IDE extensions
- **Any AI Provider** — Use OpenAI, Anthropic, Google, or 75+ other LLM providers
- **Open Source** — Fully transparent and customizable
